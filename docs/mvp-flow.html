빈 필드 대응 MVP — UI/UX 흐름

공동영농 법인이 목표 순수익(평당 배당)을 정해 두고 농가를 설득하다가, 누군가 거절해 필드에 구멍이 났을 때 쓰는 화면이다.

화면 속 숫자는 가상 들녘(시드 7)의 계산값을 바탕으로 만든 예시다. 실제 들녘 수치가 아니다.

1. 전체 흐름

STEP 1
목표 입력
목표 평당 배당(또는 순수익), 정부 면적 기준(20ha / 50ha), 최소 농가 수
STEP 2
단지 불러오기
후보단지 시뮬레이터에서 고른 단지와 현재 순수익·배당을 보여 줌
STEP 3
거절 필지 클릭
지도에서 필지(또는 농가 전체)를 눌러 해제. 1초 안에 다시 계산
STEP 4
자동 판정
① 면적·농가 수·연결성 기준 충족 여부
② 목표 평당 배당 달성 여부
STEP 5
결과 탭 3개
대체 후보 · 기계비 · 배당과 흉년

경우 A구멍이 나도 기준과 목표를 모두 충족

  1. "빼고 가도 됩니다" 표시
  2. 바로 ③ 배당과 흉년 탭으로 이동해 남은 조합원 배당 변화를 보여 줌
  3. 참고로 대체 후보도 보여 줌 (넣으면 얼마나 더 좋아지는지)

경우 B기준 미달 또는 목표 미달

  1. 무엇이 부족한지 표시 (예: 면적 1.4ha 부족)
  2. ① 대체 후보 탭 자동 열림. 기준을 넘기는 후보만 순위대로 표시
  3. 후보를 누르면 지도에 편입 땅·새 트랙터 경로가 겹쳐 보임
  4. ② 기계비 탭에서 후보별 기계비 차이 확인
마지막 단계 (공통) — 고른 안으로 ③ 배당과 흉년을 확인하고 "설득용 카드"를 내보낸다. 카드에는 해당 농가에게 평당 최대 얼마까지 제시할 수 있는지가 들어간다. 다른 필지를 또 해제하면 STEP 3으로 돌아가 결과가 계속 쌓인다.

4. 기술적으로 가능한가 — 기존 코드와 새로 만들 것

기능이미 있는 것새로 만들 것난이도
클릭 해제 → 재계산지도 클릭(web/operations.js), 비용·순이익 계산(server/metrics.py evaluate)해제 상태를 서버로 보내는 API 1개, 결과 즉시 갱신쉬움
기준 판정면적·농가 수·연결성 제약(server/selection.py)기준값(20/50ha) 화면 전환쉬움
MVP 1 대체 후보 순위인접 그래프, 경작권 교환(server/exchange.py)주변 후보 생성 + 1~3개 조합 탐색 + "목표 충족, 설득 인원 최소, 배당 최대" 순 정렬보통
MVP 2 기계비 비교작업시간·세팅·이동 비용, 순회 경로(server/routing.py)후보별 기계비 분해 표, 경로 겹쳐 그리기쉬움
MVP 3 배당배분 기준 4종(server/sharing.py)평당 배당 기준 표시, 고정 임차료형·혼합형 지급 방식 추가쉬움
MVP 3 흉년없음. 지금은 작물 소득을 "소득" 한 값으로만 가짐조수입·경영비 분리 파라미터, 작황 계수, 고정비(감가상각·인건비), 재해보험 보전(선택)새 모델
실제 들녘 소유자가상 들녘은 소유자 있음. 실측 지도는 필지 수로 추정법인이 참여·거절 농가를 직접 입력하는 방식데이터

계산 시간: 30ha 단지에서 비용 평가는 수십 ms, 작목 배치는 1초 안쪽이다. 후보 조합 수백 개를 평가해도 몇 초 안에 끝난다(작목 배치는 최종 상위 후보에만 다시 푼다).
