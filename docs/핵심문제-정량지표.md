# 핵심 문제의 정량 지표

> 문제 정의: **그 지역에서 농사짓던 소수의 주도자가, 그해 수확 결과를 알기 전에, 마을 지주들에게 평당 배당을 약속하고 땅을 받아야 한다.**

출처는 `research_notes/공동영농법인 조직과 필지 집적 과정/`의 노트에 URL과 함께 있다. 2026-10-31 기준이다.
"실적"은 보도된 결과, "발언"은 대표나 농가의 말을 옮긴 것, "통계"는 조사기관 수치다.

## 1. "소수의 주도자가" — 주도자 대 지주의 비대칭

| 지표 | 수치 | 근거 |
|---|---|---|
| 문경 영순: 주주 농가 수 대 면적 | 80농가, 110ha(2026년 약 140ha) | 실적, 농민신문 2024-06 |
| 농가당 평균 위탁 면적 | 약 1.4ha | 계산(110ha ÷ 80) |
| 농가별 위탁 면적 범위 | 300평 ~ 1만 4,000평(약 47배 차이) | 실적, 농민신문 2024-06 |
| 주주 연령 | 최연소 72세, 최고령 95세 | 발언, 한국농업신문 2023-11 |
| 영덕 달산 주민 평균 연령 | 70세 가까움, 최고령 참여 92세 | 보도, 농민신문 2025-01 |
| 전국 농가 인구 중 65세 이상 | 51.3% | 통계, 2025 농림어업총조사 |
| 2026년 2월 기준 경북 추진 지구 | 21개 지구, 배당 법인 10개 | 실적, 경북도 |
| 농업법인 중 실제 운영하지 않는 비율 | 43.9%(2019) | 통계, 노트 5 |

- 실제 농사는 청년농과 외국인 근로자가 짓는다. 2023년 노임 총액은 3억 4,100만 원이다(국민일보 2024-05).
- 주도자 수 자체(이사 몇 명, 사무장 유무)는 어느 사례에서도 보도되지 않았다.

## 2. "그해 수확 결과를 알기 전에" — 약속과 결과 사이의 시간과 변동

| 지표 | 수치 | 근거 |
|---|---|---|
| 약속 시점 → 결과 시점 | 설명회 2022년 하반기 → 파종 2023-06 → 1차 배당 2023-12-28 → 2차 배당(콩 판매 후) 2024-01 | 실적, 매일신문 2023-12 |
| 약속에서 첫 지급까지 | 약 1년(신규 단지는 1~1.5년) | 실적 종합 |
| 배당 재원이 확정되는 시점 | 콩 판매 종료 후(정부 비축 매입 기간 12-01 ~ 3-31) | 농식품부 2025년산 계획 |
| 문경 1년차 작황 | 집중호우로 작황 부진에도 약속한 3,000원 지급 | 발언, 경북매일 2023-12 |
| 경북 들녘특구 2025년 | 파종기·수확기 폭우로 콩 수확량 감소, 배당 전년 대비 감소(수치 미공개) | 보도, 아시아투데이 2026-08 |
| 논콩 정부 매입가(2025년산, 대립) | 특등 4,800 / 1등 4,560 / 2등 4,330 / 3등 3,870 / 등외 3,180원/kg | 농식품부 |
| 등급에 따른 수입 차이 | 특등 대비 등외 −34% | 계산 |
| 2026년 논콩 수매 | 정부 축소 방침, 전북·경북 도의회 철회 촉구 | 보도, 2026-07/08 |
| 들녘경영체 중 이익금이 없는 곳 | 43.6%(55개소 조사) | 통계, KREI 2015 |
| 들녘경영체 애로 | 수익성 36.4%, 합의 도출 25.5% | 통계, KREI 2015 |

- 2세대 단지(의성, 구미)는 기본배당을 1,000~1,500원으로 낮게 약속하고 실적에 따라 올려 지급했다. 1세대 문경의 3,000원 고정 약속과 달리 흉작 위험을 줄인 설계다.

## 4. "평당 배당을 약속하고" — 약속 금액과 재원

| 지표 | 수치 | 근거 |
|---|---|---|
| 경북 지구별 기본배당 단가 | 3.3㎡당 1,500원(청도) ~ 4,000원(경주 외동) | 실적, 경북일보 2026-01 |
| 단가를 정한 근거 | 공개된 적 없음 | 공백 |
| 기존 임차료 대 배당(고령농 기준) | 논 1,000㎡ 연 23만 원 → 90만 원(3.9배) | 보도, 한국경제 2026-09 |
| 들녘경영체 임차료(이모작 가능) | 40a당 121만 9천 원 | 통계, KREI 2015 |
| 문경 1년차 배당 | 3,000원, 총 9억 9,800만 원, 80농가 | 실적 |
| 문경 2년차 | 총수익 48억 → 인건비·경영비 제외 법인수익 23억 → 배당 3,500원(기본 3,000 + 성과 500), 노임 포함 농가 평균 4,700원 | 실적, 중앙일보 2025-07 |
| 2년차 법인수익 중 배당 비중 | 약 절반(110ha × 3,500원 ≈ 11.6억) | 계산, 추정 |
| 영덕 1차 배당 | 28농가, 3,000원, 농가별 73만 ~ 1,800만 원 | 실적, 농민신문 2025-01 |
| 의성 단북 | 약속 1,000원 → 실제 2,000원 | 실적 |
| 노임 | 일반 9만 원/일, 농기계 15만 ~ 30만 원/일 | 실적 |
| 농가 소득 변화(ha당) | 벼 700만 원 → 1,000만 원 이상(임대료+배당) | 분석, KREI 김정섭 |
| 법인 생산액 변화(문경) | 벼 단작 7억 7,900만 원 → 이모작 24억 7,900만 원 | 실적, 경북도 분석 |

- 문경의 "배당"은 법적으로 임대차 계약의 고정 임차료다. 지분 배당이 아니므로 흉작이어도 지급 의무가 있다.

## 5. "땅을 받아야 한다" — 설득 비용과 집적 속도

| 지표 | 수치 | 근거 |
|---|---|---|
| 주민 설명회 | 문경 10회 이상, 영덕 10여 차례 | 발언, 2023-11 / 2025-01 |
| 설명회 → 첫 파종 | 반년 ~ 1년 | 실적 종합 |
| 법인 설립 → 첫 파종(문경) | 약 5개월(2023-01 → 2023-06) | 실적 |
| 첫 배당 뒤 변화 | 영덕, 의성 모두 참여 희망 농가 증가(수치 없음) | 보도 |
| 경북 지원 기준 완화 효과 | 50ha → 20ha 완화(2025-03) 후 반년 만에 21개 지구, 530ha 전환 | 실적 |
| 2027년 기준(추진 중) | 20ha → 50ha, 연접 기준 강화 | 미확정, 농식품부 2026-09 |
| 농지은행 임대수탁 신청 처리 | 2026-10-21부터 서명 1회, 9.5분 → 4분 | 실적 |
| 80ha 이상 법인의 필지 분산 | 분산 필지로 기계화 효율 저하 | 보도, 농민신문 2025-01 |

## 여기서 숫자로 확인되지 않은 것

- 주도자 수와 법인 내부 인력(이사, 사무장, 작업단).
- 들녘 안 비참여 농가 비율과 구멍 필지 수.
- 설명회 참석률, 동의서 회수율, 설득에 걸린 개월 수.
- 배당 단가 산정 근거와 흉작 시 배당 감소 폭.
- 법인 유보금 규모와 운영비 비율.

이 다섯 가지는 법인 대표 인터뷰로만 채울 수 있다. 그 전까지 문제 정의의 수치는 위 표까지다.
