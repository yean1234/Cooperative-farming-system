# 모두의 농장 판넬 — 설계 기록 (v3.1)

OPEN HARBOR 2026 비즈니스톤 부스 판넬(완성 1200×1800mm 세로형, 작업 1220×1820mm, PDF 제출)의 설계 근거다.
`panel.html`이 원본이고 `node docs/panel/build.js`가 `비즈니스톤_물개_모두의농장_판넬.pdf`와 `preview.png`를 만든다(Playwright·Chromium·pdftoppm, 시스템에 Wanted Sans 설치 필요).

v3는 사용자가 보여 준 UX 포트폴리오형 판넬 4종(RE:WAVE, DO:RE, Harmoni, CASSETTE)의 공통 구조를 따른다.

## 1. 레퍼런스에서 읽은 패턴 → 적용

| 레퍼런스의 공통 패턴 | 이 판넬 |
|---|---|
| 브랜드색 헤더, 아래 가장자리가 물결(곡선) | 들녘 초록 헤더, 논둑처럼 굽는 곡선 한 번 + 연한 물결 한 겹 |
| 앱 아이콘 타일 + 워드마크 + 태그라인 + 소개 문단 | 흰 타일 안의 마크, "모두의 농장" 60mm, 태그라인 27mm, 소개 4줄 |
| 헤더에 걸치는 기기 목업(기울어진 폰) | 웹 서비스이므로 브라우저 창(−3°)과 인쇄물 A4 종이(+5°). 목업에만 그림자 허용 |
| 떠 있는 장식 도형 | 로고와 같은 둥근 필지 조각, 기울어진 노랑은 하나뿐 |
| Background / Pain Point / Solution 3열, 영문 소제목 | 같은 3열. 배경에는 작은 차트, 불편 3개는 번호, 해결은 1:1 대응 상자 |
| Persona(말풍선) · Key Insight(원 3개) | 실제 인터뷰 발언으로 구성: 경주시청 농정과(전화, 녹음 전사 `docs/interviews/`), 상주시청 농정과(전화), 문경·영덕 법인 대표(보도). 인사이트 셋도 인터뷰에서 바뀐 것(주체는 법인 · 집단화·면적 · 예비 법인부터) |
| Logo System 자리 | 디자인 시스템 대신 **서비스 이야기**: 꼭 알려야 할 핵심 기능 3(기준 판정·대체 필지 / 평당 배당·흉년 / 설명 자료 인쇄), 계산 방식(공개 데이터 3종 → 필지 인접 그래프 → 제약 탐색 → 브라우저 계산, 머신러닝 대신 최적화를 고른 이유), 검증 계획(12월 명부 대조 ±15%, 2027 보정·무료 설계 3곳 적중률). 모두 1차 제출 보고서 III장·3.3절에서 가져왔다 |
| 하단 Screen Flow(화면 여러 장) | 시제품 화면 5장: 후보단지 → 거절 누르기 → 대체 필지 → 배당·흉년 → 설명 자료 |

## 2. 제작 기준(Notion '판넬 제작 기준')과 대응

| 기준 | 대응 |
|---|---|
| 완성 1200×1800mm, 작업 1220×1820mm | `@page 1220mm×1820mm`, 바탕을 사방 10mm 밖까지 채움 |

## 4-1. v3.1에서 바꾼 것 (피드백 반영)

- **검증되지 않은 시간 수치 삭제.** "판정 0.01초", "1초 만에", "0.4초"는 시제품 화면에 찍힌 측정값일 뿐 현장에서 검증된 숫자가 아니라 모두 뺐다. 대신 "거절 당일", "기준 자동 판정", "바로 계산"으로 적었다.
- **Persona를 실제 인터뷰로.** 경주시청 통화 녹음(7분 24초)을 Whisper로 전사해 `docs/interviews/2026-10-29-gyeongju-transcript.txt`에 두고, 판넬에는 정리한 발언만 인용했다. 상주시청 발언은 1차 보고서 2.2절, 법인 대표 발언은 보도(농민신문 2025.1)에서 가져왔으며 출처를 말풍선에 표기했다.
- **디자인 시스템 설명을 서비스 설명으로.** 로고·컬러·타이포 소개는 브랜드 키트(`docs/brand/`)로 보내고, 판넬에는 기능·기술·검증 계획을 넣었다.

## 5. 자기 비평과 점검

- **위계(critique):** 2m에서 워드마크·태그라인·헤더 목업만 보이고, 1m에서 세 섹션 제목과 원 3개, 바로 앞에서 화면과 숫자가 읽힌다(철학의 '세 거리').
- **인지 부하(ux-heuristics):** 섹션 5개, 번호는 실제 순서(불편 1·2·3 ↔ 해결 1·2·3, 화면 흐름 1~5)에만 썼다. 비교표·흐름도는 QR 뒤 문서로 보냈다.
- **접근성(accessibility-auditor):** 흰 글자/초록 5.5:1, 본문 `#4D5851`/흰색 7.2:1, 보조 `#6C766F` 4.9:1, 칩의 노랑 글자는 굵은 14.5mm(큰 글자)로 초록 위 3.5:1. 빈 땅은 점선, 페르소나는 글자와 아이콘, 차트 값은 직접 표기 → 색만으로 뜻을 전하는 곳이 없다.
- **인쇄:** 글꼴 CID TrueType 임베드, 화면 캡처 3배 해상도(헤더 브라우저 4,320px 폭 → 548mm에서 약 200dpi).
- **철학 대비 예외:** 목업(브라우저·종이)에만 그림자를 썼다. 평면 도형이 아니라 '놓인 물건'이기 때문이며, 그 외 그림자·그라데이션은 없다.
