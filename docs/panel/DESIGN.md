# 모두의 농장 판넬 — 설계 기록 (v2)

OPEN HARBOR 2026 비즈니스톤 부스 판넬(완성 1200×1800mm 세로형, 작업 1220×1820mm, PDF 제출)의 설계 근거다.
`panel.html`이 원본이고 `node docs/panel/build.js`가 `비즈니스톤_물개_모두의농장_판넬.pdf`와 `preview.png`를 만든다(Playwright·Chromium·pdftoppm 필요, Wanted Sans가 시스템에 설치돼 있어야 한다).

## 1. 제작 기준(Notion '판넬 제작 기준')과 대응

| 기준 | 대응 |
|---|---|
| 완성 1200×1800mm, 작업 1220×1820mm | `@page 1220mm×1820mm`. 초록·연회색 바탕을 사방 10mm 밖까지 채움 |
| 중요 내용은 가장자리에서 떨어뜨림 | 글자·QR·로고는 재단선에서 50mm 이상 안쪽(안전 여백 60mm) |
| 상단: 서비스명·로고·한 줄 소개 | 로고 락업 + "농가 한 곳이 빠져도, 공동영농은 계속됩니다" + "거절로 생긴 빈 땅을 1초 만에 다시 설계하는 공동영농 법인의 도우미" |
| 문제: 짧은 문장 | 숫자 3개(설명회 10회·1~1.5년 / 20ha·5명 / 평당 1,500~4,000원) + 한 줄씩 |
| 솔루션: 핵심 기능 2~4개와 실제 화면 | 세 단계(누른다 → 답이 나온다 → 뽑아 건넨다), 시제품 화면 3배 해상도 캡처 |
| 하단: QR·팀명 | GitHub 저장소 QR(README를 고치면 최신 내용 반영), 팀 물개 |
| 2~3m에서 제목이 읽힘 | 헤드라인 60mm, 섹션 제목 44mm, 본문 19mm 이상, 캡션 12.5mm 이상 |
| 피드백 후에도 바뀌지 않을 내용 | 문제 정의·제품 화면·데이터 구조 위주. 일정은 하단에 작게 |
| 파일명 규칙 | `비즈니스톤_물개_모두의농장_판넬.pdf` |

## 2. 디자인 방향: "한 눈에, 초보자도"

- **한 가지 그림이 전부를 말한다.** 상단 오른쪽의 '빈 땅에 대체 땅이 들어오는' 그림이 제품의 작동 원리다. 로고 마크(모이는 필지)와 같은 둥근 필지 조각, 같은 기울기(−14°)로 그려 로고와 그림이 한 몸이 되게 했다.
- **글자는 줄이고 크게.** v1(실측 지도 히어로 + 비교표 + 데이터 흐름도)이 복잡하다는 피드백에 따라 비교표·흐름도를 빼고, 한 섹션에 한 문장만 남겼다.
- **순서가 곧 사용법.** ①②③은 장식이 아니라 사무장이 실제로 하는 행동 순서다.
- **색은 브랜드 토큰 그대로.** `docs/brand/kit/tokens/tokens.css`의 들녘 초록 `#1F7A4D`, 새순 연두 `#3F9F60`, 볏짚 노랑 `#F2B134`, 잉크 `#141F18`, 바탕 `#F9FBFA`. 빈 땅은 색이 아니라 '점선 빈 칸'으로 그려 빨강 없이도 뜻이 통한다.
- **글꼴 한 가족.** Wanted Sans 900(제목, 자간 −2.5%) / 700 / 500 / 400, 숫자는 `tnum`.

## 4. 쓴 스킬과 역할

| 단계 | 스킬 | 적용 |
|---|---|---|
| 로고·글꼴·색 | `brand-identity`(fatihaydost) | 브리프 → 3세트(메커니즘·축·경쟁 차별) → 접촉 인쇄 2회 → 측정(대비·한글 11,172자·라이선스·16/32px) → 체크포인트에서 A 선택 → 키트. 자세한 내용은 `docs/brand/BRAND.md` |
| 컨셉·팔레트 출발점 | `ui-ux-pro-max` | 카탈로그 `Agriculture/Farm Tech` 행(Organic Biophilic + Flat Design), `Accessible & Ethical` 스타일, UX 가이드(대비 4.5:1, 색만으로 뜻을 전하지 않음, 일관된 타입 스케일) |
| 판넬 구조 | claude design-skills `wireframe-agent` → `page-designer` | 위 ASCII 와이어프레임 → 섹션별 토큰·간격 명세(`panel.html`의 CSS) |
| 문구 | `content-copy-designer` + 1차 제출 보고서 문체 | 짧은 평서문("~다"), 숫자 먼저, 출처는 작게. 버튼처럼 보이는 요소는 실제 화면 문구 그대로 |
| 검토 | `design-critique`, `ux-heuristics`, `accessibility-auditor` | 아래 5절 |

로고 전용 스킬은 design-skills 18개에 없어 `component-builder`(재사용 요소의 해부도·변형·대비 요건)의 틀로 1차 안을 만들었고, '정적이다'는 피드백 뒤 brand-identity 스킬로 전면 재작업했다.

## 5. 자기 비평과 점검

- **시각 위계(critique):** 2m 밖에서 읽히는 순서가 로고 → 헤드라인 → 작동 그림 → 세 단계 제목이 되도록 크기를 60 / 44 / 27mm로 잡았다. 한 섹션에 강조색(노랑)은 한 곳.
- **인지 부하(ux-heuristics):** 섹션 5개, 문장은 섹션당 1~3개. 비교표·흐름도·부가 설명은 QR 뒤의 문서로 보냈다(Miller's Law, Aesthetic & Minimalist).
- **접근성(accessibility-auditor):** 흰 글자/초록 바탕 5.5:1, 잉크/연회색 바탕 16:1, 보조 글자 `#4D5851` 7:1. 빈 땅·대체 땅은 색과 함께 점선·글자로 구분(1.4.1). 노랑 위 글자는 잉크색만 쓴다.
- **인쇄:** 글꼴은 CID TrueType으로 임베드(Type 3 아님). 화면 캡처는 3배 해상도(가장 큰 것 2,580px 폭, 350mm 인쇄 시 약 190dpi).

## 6. 수치의 출처

- 설명회 10회 이상, 1~1.5년: 문경·영덕 법인 대표 발언(농민신문 2025.1), 경주·상주시청 농정과 인터뷰(2026.10.29)
- 20ha·5명, 2년 최대 20억 원, 탈락 사유 1위 '집단화 미비·면적 부족': 농식품부 공동영농 확산 지원사업(2026.3), 경주시청 인터뷰
- 평당 1,500~4,000원, 산정 근거 미공개: 경북 배당 법인 10개소(경북매일 2026.3)
- 흥해 2,666필지·489ha, 판정 0.01초, 거절 3농가 5.2ha → 18.1ha 미충족 → 1순위 이웃 1 편입(+2.4ha): 시제품 실행 화면(2026.11.5~7)
