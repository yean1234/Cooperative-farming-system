# R4 공동영농 필지 최적화 — 서비스 기획 초안

기획안 뼈대의 순서(초록 · 문제 · 선행 · 방법론 · 데이터 · 산출물)를 그대로 따른다.
같은 저장소의 웹 서비스 초안을 기준으로 썼다. '데모'라고 표시한 숫자는 합성 데이터(가상 들녘)로 계산한 값이다. 실제 들녘 수치가 아니다.

## 한눈에 보기

공동영농 법인이 들녘 지도를 놓고 세 가지를 한 번에 설계하도록 돕는 의사결정 지원 서비스다.

1. **어느 필지를 맞바꿔야 하나.** 이웃 농가와 경작권을 교환해 법인 경작지와 농가 경작지를 각각 한 덩어리로 모은다.
2. **무엇을 어디에 심어야 하나.** 법인 땅에 벼·가루쌀·콩·조사료를 단지로 배치한다. 담수 작목과 밭 작목이 맞닿지 않게 한다.
3. **늘어난 이익을 어떻게 나눠야 하나.** 배분 기준별로 조합원 각자가 개별영농보다 나아지는지 보여 준다.

가상 들녘 다섯 곳에서 계산한 데모 결과는 다음과 같다. 비교 기준은 현황(개별영농)이다.

| 지표 | 다자간 교환안 |
|---|---|
| 들녘 순이익 | +10.9% ~ +14.2% |
| 농기계 작업시간 | −27.1% ~ −32.2% |
| 농기계 이동거리 | −68.1% ~ −69.8% |
| 경작 블록 수 | −87.2% ~ −91.2% |
| 교환 전보다 불리해진 농가 | 0명 |

---

## 1. 초록

우리나라 논은 작은 필지가 여러 농가에 잘게 나뉘어 흩어져 있다. 농가 인구의 절반 이상이 65세 이상이라 정부와 경상북도는 여러 농가의 땅을 법인이 함께 짓는 공동영농을 늘리고 있다.
그런데 공동영농을 해도 비참여 농가의 필지가 사이사이 끼어 있으면 대형 농기계 작업과 물 관리가 끊긴다. 수익 배분 기준이 모호하면 참여도 망설여진다.

이 서비스는 필지 경계·소유·토양 데이터를 인접 그래프로 바꾼 뒤 세 단계를 계산한다.

1. 경작자별 면적·가치를 지키면서 아무도 불리해지지 않는 다자간 경작권 교환안을 찾는다(담금질 기법).
2. 법인 땅에 작목을 단지로 배치하는 혼합정수계획을 푼다(HiGHS 솔버).
3. 협력게임의 샤플리 값으로 조합원별 기여도 배분안을 만든다.

데모에서 1:1 자율 교환보다 블록 수는 44~56%, 이동거리는 23~33% 더 줄었다. 단순 면적 비례 배분은 조합원 18명 중 2~6명을 손해 보게 했다. 기여도 배분에서는 다섯 들녘 모두에서 전원이 개별영농보다 나아졌다.

## 2. 문제

### 2.1 배경

- **고령화**: 2025년 농림어업총조사에서 농가 인구 중 65세 이상 비중은 51.3%다(국가데이터처 자료, KDI 경제정보센터 정리).
- **공동영농 정책**: 농림축산식품부는 '공동영농 확산 지원사업'을 2026년 6개소로 시범 시작했다. 2030년까지 공동영농법인 100개소를 육성하는 것이 목표다.
  - 선정 법인은 2년간 개소당 20억 원을 받는다. 국비 50%, 지방비 40%, 자부담 10%다.
  - 대상은 농업인 5명 이상, 경작 면적 20ha 이상인 농업법인이다.
  - 2026년 8월 개선안으로 벼 품목 포함, 면적 기준 상향(20→50ha), 농지이용증진사업 연계, **수익분배 모델 구체화**가 검토되고 있다.
- **경북 사례**: 문경 영순 들녘은 2023년 벼 일모작 110ha를 콩·양파·감자 이모작으로 바꿨다. ha당 농업소득이 670만 원에서 3,139만 원으로 늘었다고 보도됐다(경상북도 발표 인용).
  의성 화성영농조합법인(24.7ha, 20호)은 3.3㎡당 2,000원을 배당했다.

### 2.2 현장의 문제

1. **필지가 작고 흩어져 있다.** 농기계가 필지마다 들어가 세팅하고 도로를 오가느라 시간을 쓴다. 담수 작목은 물꼬를 보러 매일 돌아야 한다.
   데모 들녘(48ha, 30농가)의 현황은 경작 블록 160개, 농기계 이동 803km/년이다.
2. **공동영농을 해도 '구멍'이 남는다.** 비참여 농가 필지가 법인 땅 사이에 끼어 있으면 단지화가 안 된다.
3. **1:1 자율 교환은 잘 성사되지 않는다.** 두 농가가 서로 원하는 필지를 마침 갖고 있어야 하는데(이중 일치), 그런 짝이 드물다(Arimoto et al., 2016).
4. **작목 전환에는 배치 문제가 따른다.** 논콩 옆에 물을 댄 벼 논이 붙어 있으면 습해 위험이 커진다. 같은 작목을 모아야 기계 작업도 이어진다.
5. **배분 기준이 불명확하다.** 면적만으로 나누면 이미 효율적으로 짓던 농가가 손해를 볼 수 있다. 정부도 수익분배 모델 구체화를 과제로 꼽았다.

### 2.3 이 서비스가 답할 질문과 범위

| 구분 | 내용 |

**차별점**: 교환·작목 배치·수익 배분을 하나의 계산 흐름으로 묶었다. 그리고 "교환 전보다 불리해지는 농가가 없을 것"을 제약으로 넣었다.
교환은 소유권이 아니라 경작권을 바꾸는 방식이다. 등기·세금 부담 없이 시작할 수 있다.

## 4. 방법론

### 4.1 계산 흐름

```
필지 GeoJSON ─▶ 인접 그래프 ─▶ S0 현황 진단(개별영농)
                              ├─▶ S1 공동영농(교환 없음) ─┐
                              ├─▶ S2 1:1 상호이익 교환 ───┼─▶ 작목 단지화 MILP ─▶ 같은 평가 모델로 비교
                              └─▶ S3 다자간 교환(제안) ───┘
                                                         S3 법인 순이익 ─▶ 조합원 수익 배분
```

### 4.2 인접 그래프

두 필지 경계가 8m 이내에서 서로 마주 보는 구간이 5m 이상이면 인접으로 본다.
폭 8m 이하의 농로·수로를 사이에 둔 필지는 농기계가 곧바로 건너갈 수 있다. 그래서 같은 작업 블록으로 본다.
경계가 1.5m 이내로 붙어 있으면 논두렁을 맞댄 것으로 표시한다. 이 표시는 습해 판단과 대구획화에 쓴다.
모서리만 맞닿은 대각선 필지는 제외한다. 투영점이 꼭짓점에 걸리는지로 판정한다.

### 4.3 평가 모델

네 시나리오를 같은 모델로 평가한다.

```
작업시간 = Σ작업 횟수 × ( Σ포장 면적 / (작업능률 × 포장효율(면적))   # 필지 작업
                        + 블록 수 × 진입·세팅 시간                       # 블록마다 한 번
                        + (포장 수 − 블록 수) × 블록 내 이동 시간
                        + 순회 경로 길이 × 우회계수 / 주행속도 )         # 블록 중심 순회
포장효율(a) = 0.85 × a / (a + 0.06ha)
순회 경로 = 출발지(집 또는 법인 농기계 보관소) → 블록 중심 → 출발지  (최근접 이웃 + 2-opt)
순이익 = 작물 소득 + 전략작물직불금 − 기계 작업비 − 물꼬·생육 순회비 − 법인 운영비 ± 임차료 정산
```

- **대구획화 가정(기본값)**: 법인 경작지에서 같은 작목으로 논두렁을 맞댄 필지는 한 포장으로 정비해 짓는다고 본다. 공동영농 지원사업의 '기반 정비'에 해당한다. 화면에서 끌 수 있다.
- **임차료 정산**: 교환으로 남의 땅을 지으면 평가가치의 1.5%를 연 임차료로 주고받는다고 가정한다.
- **집단화 지수**: K = √(ΣA) / Σ√A 다. 블록이 하나면 1이고, 잘게 흩어질수록 0에 가까워진다.

### 4.4 경작권 교환 최적화

**결정**: 교환 가능한 필지마다 경작자(법인 또는 개별 농가) 하나를 정한다.

**경작자 분산 점수**:

```
s_f = w_block·(블록 수 − 1) + w_disp·(면적가중 평균 분산거리 / 100m) + w_base·(거점까지 평균거리 / 100m)
```

기본 가중치는 1.0, 0.5, 0.2다. 법인 점수에는 가중치 2를 곱한다.

**목표**: Σ 가중 분산 점수 + 0.15 × (경작자가 바뀐 필지 수)를 최소화한다. 뒤의 항은 합의 부담을 반영한다.

**제약**:

- 경작자별 면적 변화가 ±10% 이내다.
- 경작자별 평가가치 변화가 ±10% 이내다. 평가가치는 공시지가 × 면적 × 토양계수다.
- 시설하우스, 교환 미동의 필지는 고정한다.
- **개별 합리성**: 비참여 농가의 분산 점수가 교환 전보다 나빠지지 않는다.

**기준선(1:1 교환)**: 두 경작자가 필지 하나씩 맞바꾼다. 양쪽 점수가 모두 좋아질 때만 성사된다.
쌍방 공시지가 가액 차이가 큰 쪽의 1/4 이하라는 요건도 적용한다. 이는 농지 교환 양도세 비과세 요건이다(소득세법 제89조 제1항 제2호, 시행령 제153조).
성사될 거래가 없을 때까지 반복한다.

**제안안(다자간 교환)**: 담금질 기법으로 탐색한다.

- 이동은 교환(swap)과 이전(transfer) 두 가지다. 후보는 경계에 맞닿은 필지를 우선 뽑는다.
- 기본 탐색 횟수는 40,000회다. 시작 온도는 나빠지는 이동의 중앙값이 50% 확률로 받아들여지도록 정한다.
- 원래 배정과 1:1 교환 결과, 두 곳에서 각각 출발해 더 나은 해를 고른다.
- 개별 합리성은 벌점으로 다룬다. 끝에 위반이 남으면 해당 농가의 교환을 되돌리는 보정 단계를 거친다.

### 4.5 작목 단지화 혼합정수계획

법인 경작 필지 p마다 작목 c ∈ {벼, 가루쌀, 콩, 조사료}를 하나 고른다.

```
최대화  Σ_p Σ_c 소득(p,c)·x[p,c]                       # 토양등급·배수등급 계수, 전략작물직불금 반영
       + λ Σ_(p,q)∈E Σ_c 경계길이(p,q)·w(p,q)·z[p,q,c]  # 같은 작목 인접 보상, λ=1,000원/m (농로 건너 인접은 w=0.6)
       − μ Σ_(p,q)∈E_맞닿음 경계길이(p,q)·u[p,q]        # 담수·밭 작목 맞닿음 벌점, μ=1,500원/m
제약    Σ_c x[p,c] = 1
       z[p,q,c] ≤ x[p,c],  z[p,q,c] ≤ x[q,c]
       u[p,q] ≥ Σ_담수 x[p,c] + Σ_밭 x[q,c] − 1  (반대 방향도 같은 꼴)
       하한_c · A ≤ Σ_p 면적(p)·x[p,c] ≤ 상한_c · A
       재배 적합성: 벼·가루쌀은 관개되는 논, 콩은 배수 보통 이상
```

- **작목 비율 기본값**: 벼 ≤70%, 가루쌀 ≤20%(가공 계약), 콩 10~40%, 조사료 ≤15%(인근 축산 수요)다.
- **이웃 처리**: 법인 밖 이웃 필지(비참여 농가의 벼 논 등)는 상수로 보고 습해 벌점에 반영한다.
- **풀이**: SciPy의 HiGHS로 푼다. 데모 규모(이진변수 약 370개)는 1초 안에 최적해가 나온다.
- **비율 충돌 시**: 비율 조건이 서로 맞지 않으면 비율 제약을 풀고 다시 푼 뒤 화면에 알린다.

### 4.6 수익 배분

S3 법인 순이익을 네 기준으로 나눈다. 각 조합원의 몫을 현황(S0)에서 자기 필지를 따로 지을 때의 순이익과 비교한다.

| 기준 | 정의 |
|---|---|
| 면적 비례 | 출자 면적 비율 |
| 생산력 환산면적 비례 | 면적 × 토양등급 계수 비율 |
| 토지·노동 혼합 | 생산력 환산면적 80% + 법인 작업 참여 일수 20% |
| 기여도(샤플리) 비례 | 아래 협력게임의 샤플리 값 비율 |

기여도 배분의 특성함수 v(S)는 조합원 부분집합 S가 자기 필지만으로 공동영농할 때의 순이익이다.

- **비용 구성**: 포장 작업비, 블록 진입비, 이동비(최소신장트리 근사), 순회비가 S의 공간 배치에 따라 달라진다.
- **기여의 의미**: 다른 조합원 필지를 이어 주는 필지를 낸 농가는 기여가 크게 잡힌다.
- **근사 방법**: 무작위 순열 150개로 몬테카를로 근사한다. 순열 안에서는 union-find로 블록을 점진적으로 갱신해 1초 안팎에 계산한다.

### 4.7 실험 설계와 데모 결과

**설계**: 가상 들녘 다섯 곳(시드 1, 2, 3, 7, 11)에 네 시나리오를 적용했다. 각 들녘은 약 48ha, 필지 약 172개, 농가 30호, 참여율 60%다.
대구획화 가정을 켠 경우와 끈 경우를 모두 돌렸다. 한 번 계산하는 데 3~4초가 걸렸다.

**시드 7 결과**(웹 화면 기본값):

| 시나리오 | 경작 블록 | 기계 작업시간(h) | 기계 이동(km) | 들녘 순이익(백만원) | 법인·조합원 필지 순이익(백만원) |
|---|---|---|---|---|---|
| S0 개별영농 | 160 | 1,124 | 803 | 240.2 | 168.1 |
| S1 공동영농, 교환 없음 | 54 | 832 | 360 | 268.4 | 196.3 |
| S2 공동영농 + 1:1 교환 | 25 | 790 | 332 | 271.4 | 197.6 |
| S3 공동영농 + 다자간 교환 | 14 | 762 | 253 | 274.2 | 201.0 |

교환 필지 수는 S2가 52개(13.5ha), S3가 65개(18.4ha)다.

**다섯 들녘에서 확인한 것**(대구획화 가정 기본값):

- **순서**: 들녘 순이익은 다섯 곳 모두 S0 < S1 < S2 < S3 순서였다. 법인 순이익도 모두 S3가 가장 높았다.
- **현황 대비 S3**:

  | 지표 | 변화 |
  |---|---|
  | 들녘 순이익 | +10.9~14.2% |
  | 작업시간 | −27.1~32.2% |
  | 이동거리 | −68.1~69.8% |
  | 블록 수 | −87.2~91.2% |

- **1:1 교환 대비 S3**: 블록 수 −44.0~55.8%, 이동거리 −22.8~32.7%. 1:1 교환으로 남는 '이중 일치' 한계를 다자간 설계가 메운다는 선행연구 결론과 같은 방향이다.
- **개별 합리성**: 교환 전보다 분산 점수가 나빠진 비참여 농가는 다섯 곳 합계 0명이다.
- **배분 기준 비교**:

  | 배분 기준 | 개별영농보다 나아진 조합원 |
  |---|---|
  | 면적 비례 | 18명 중 13~16명 |
  | 생산력 환산면적 비례 | 12~16명 |
  | 토지·노동 혼합 | 12~16명 |
  | 기여도(샤플리) 비례 | 다섯 곳 모두 18명 |

- **평당 배분액**: 1,906~2,087원이다. 의성 사례의 3.3㎡당 2,000원 배당과 같은 수준이라 가정값의 규모는 어긋나지 않는다. 다만 검증은 아니다.
- **대구획화 가정을 끄면**: 순서는 그대로다. S3의 순이익 개선은 현황 대비 +9.5~11.5%로 줄어든다. 기여도 배분은 한 들녘에서 1명이 개별영농보다 낮아졌다.

### 5.2 입력 형식

EPSG:4326 GeoJSON FeatureCollection을 그대로 올리거나, 아래 시나리오 JSON으로 감싸 올린다. 서버가 인접 관계를 계산해 돌려준다.

| 필지 속성 | 의미 | 기본값 |
|---|---|---|
| `id` | 필지 식별자(PNU 권장) | 순번 |
| `land_type` | 답 또는 전(논·밭도 허용) | 답 |
| `owner` | 소유(경작) 농가 id | 필수 |
| `soil_grade` | 토양 적성등급 1~4 | 2 |
| `drainage` | 배수등급 1 양호, 2 보통, 3 불량 | 2 |
| `irrigated` | 관개 가능 여부 | 논이면 true |
| `land_value` | 공시지가(원/㎡) | 30,000 |
| `exchangeable` | 교환 대상 여부 | true |
| `crop_locked` | 작목 고정 여부(시설 등) | 시설채소면 true |
| `current_crop` | 벼, 가루쌀, 콩, 조사료, 시설채소 중 하나 | 논 벼, 밭 콩 |

시나리오 JSON은 `{ "parcels": FeatureCollection, "farmers": [...], "depot": [경도, 위도] }` 형태다.
`farmers` 항목은 `id`, `name`, `age`, `member`(조합원 여부), `home`(경도, 위도), `labor_days`로 이뤄진다.
농가 정보가 없으면 모든 소유자를 조합원으로 보고 경고를 띄운다.

### 5.4 개인정보와 동의

### 6.3 해커톤 제출물 구성(안)

1. 웹 서비스 시연. 가상 들녘에서 현황 → 공동영농 → 1:1 교환 → 다자간 교환 순서로 보여 준다.
2. 이 기획 문서와 방법론 요약 발표 자료
3. 데모 결과표(4.7절)와 민감도 분석(대구획화 가정 켜고 끄기, 참여율·분산도 변화)
4. 실제 들녘 1곳에 적용하는 계획. 경북 공동영농 법인 등과 협의하는 것을 전제로 한다.

### 6.4 다음 단계

1. **실데이터 연동**: 연속지적도·팜맵·흙토람 데이터를 실제 들녘 한 곳에 붙여 인접 판정과 지표를 검증한다.
2. **이모작 모델**: 동계 밀·조사료와 하계 콩·가루쌀을 묶는 2기작 배치. 이모작 직불금 100만 원/ha를 반영한다.
3. **작업 일정**: 이앙·수확 적기와 기계 대수를 고려한 작업 순서와 일정 계획
4. **교환 방식 비교**: 최상위 거래 순환(TTC)을 추가 기준선으로 넣는다. 소유권 교환 모드(1/4 가액 요건, 3년 경작 요건)도 추가한다.
5. **합의 도구**: 농가별 "내 필지 변화 카드"를 만든다. 교환 제안에 대한 동의·거절을 받아 반영하고 다시 계산한다.
6. **파라미터 교체**: 농촌진흥청 소득자료집, 지역 임차료, 실제 기계 비용으로 가정값을 바꾼다.

### 6.5 확인이 필요한 가정

- 대상 지역과 들녘 규모. 이 초안은 포항 흥해 인근을 가정한 가상 들녘이다.
- 문제 범위의 무게중심을 교환, 작목, 배분 중 어디에 둘지
- 평가 지표. 이 초안은 블록 수, 작업시간, 이동거리, 순이익, 개별 합리성, 배분 후 손해 조합원 수를 쓴다.
- 데이터 확보 경로와 일정. 특히 소유·참여 정보와 토양·관개 정보
- 직불금 단가 원문, 작목 소득·기계 비용 실제값
