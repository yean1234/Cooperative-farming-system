# 타겟 분석 — 빈 필드 시뮬레이터는 누구에게 무엇을 보여 줘야 하나

빈 필드 시뮬레이터(`web/empty-field.html`)와 '모두의 농장' 공통 화면의 설계 근거다. 공개 자료와 최종발표의 고객 가설로 타겟을 정하고, 화면에서 바꾼 부분을 그 근거에 연결한다.
인터뷰 전 가설이다. 인터뷰 답변이 들어오면 이 문서와 화면을 함께 고친다.

## 1. 공개 자료에서 확인한 사실

| 사실 | 출처 | 화면에 주는 뜻 |
|---|---|---|
| 지원은 법인당 2년 최대 20억 원(국비 50·지방비 40·자부담 10%). 2026 시범 6개 법인 | 뉴시스, 농식품부 공동영농 확산 민·관 협의체 첫 회의(2026.7.27) | 지원 자격을 잃는 손실이 크다. 자격 판정을 화면 맨 위에 둔다 |
| 면적 기준 상향(20ha→50ha), 벼 포함을 검토 중. 개선안은 2026년 11월까지 | 같은 협의체, 농식품부 차관 경주 대청 현장 점검 보도 | 기준이 바뀔 수 있다. 기준을 고정하지 않고 고를 수 있게 둔다 |
| 협의체 검토 과제: 농지 집적화, 품목 구성, **소득 배분**, 사업 운영 | 같은 협의체 | 배분 방식(배당·임차료·혼합) 비교가 정책 쟁점과 맞닿아 있다 |
| "확산에는 신뢰와 참여가 가장 중요" | 같은 협의체, 차관 발언 | 약속처럼 보이는 숫자 대신 범위와 추정치임을 밝힌다 |
| 배당 법인 10개소(2026.2), 의성 화성영농조합법인 평당 2,000원 배당 | 경북매일(2026.3.17) | 농가는 "평당 얼마"로 생각한다. 평·만 원 단위로 보여 준다 |
| 농가 인구 중 65세 이상 51.3%(잠정, 농가) · 51.0%(확정, 농림어가) | 국가데이터처 2025 농림어업총조사(잠정 2026.4.28, 확정 2026.9.29) | 설득 대상 조합원 절반이 고령이다 |
| 디지털 역량 수준(일반 국민 대비): 농어민 72.4%, 고령층 56.2% | 과기정통부·NIA 2025 디지털정보격차 실태조사(2026.3) | 조합원은 화면을 직접 쓰지 않는다. 사무장이 인쇄해 건넬 큰 글자 자료가 필요하다 |

> 발표자료의 "농업인 5명 이상" 요건은 공개 보도에서 확인하지 못했다. 공고문 원문으로 확인한 뒤 쓴다. 화면에서는 최소 참여 농가를 바꿀 수 있게 두었다.
> 65세 이상 비율은 확정 결과(51.0%, 농림어가 기준)가 나왔다. 발표자료의 51.3%는 잠정 결과(농가 기준)다.

## 2. 세 사람이 각자 원하는 것

최종발표의 구매 구조(사무장이 쓰고, 대표가 정하고, 법인이 비용을 낸다)를 따랐다.

| 누구 | 역할 | 거절 당일 묻는 것 | 받아야 할 것 |
|---|---|---|---|
| 사무장 | 최종사용자 | 빼고 가도 지원 기준이 지켜지나? 메워야 하면 누구를 설득하나? | 한 줄 결론, 1순위 대안, 설득할 농가 수 |
| 대표 | 의사결정자 | 순수익이 얼마나 줄고, 어떤 안을 고를까? | 대안 3개 비교와 권고, 결정할 일이 적힌 한 장 |
| 남은 조합원 | 설득 대상(간접) | 내 배당이 줄어드나? 흉년이면 어떻게 되나? | 평당 배당과 내 땅 기준 금액, 흉년 손해를 누가 지는지 |

시뮬레이터로 확인한 핵심 숫자도 있다. 흥해 단지 6에서 한 농가가 빠지면 법인 순수익은 3~10% 줄지만, 남은 조합원 평당 배당은 0.3% 안쪽으로만 줄었다. 땅과 배당받을 사람이 함께 빠지기 때문이다. 이 숫자가 조합원 설득의 첫 문장이 된다.

## 3. 화면에서 바꾼 것

| 바꾼 것 | 근거 |
|---|---|
| **결론 영역**을 화면 맨 위로 올림: 빼고 갈지·메울지 한 줄, 지원 기준, 법인 순수익 변화, 남은 조합원 평당 배당 변화, 다음 할 일(1순위 대안) | 사무장이 가장 먼저 묻는 질문. 이전에는 오른쪽 탭 안 배너에 있었다 |
| 판정 시간 표시(예: 판정 0.01초) | 가치제안 "1초 안에 판정"을 화면에서 바로 보여 준다 |
| **거절 기록**: 거절한 순서대로 농가와 면적, 농가별 복구 버튼 | 여러 농가가 거절하면 누가 빠졌는지 기억해야 했다. 지도를 다시 찾지 않고 되돌린다 |
| **설명 자료 만들기**: 대표 보고용 한 장, 농가 설명용 한 장(인쇄, A4) | 대표는 결정, 조합원은 종이로 받는다. 디지털 역량 격차를 사무장이 메운다 |
| 농가 설명용 자료: 글자 크게, 평당 배당과 1,000·2,000·3,000·5,000평 기준 연 금액, 흉년 손해를 지는 쪽, "추정치이며 약속이 아님" | 고령 조합원, 평 단위 사고, 배당 신뢰 문제 |
| 배당금·흉년 탭 첫 줄에 "흉년이면 배당형은 조합원이, 고정 임차료형은 법인이 손해" 문장 | 발표 인사이트 "흉년은 따로 보여 줘야 설득된다" |
| 본문 16px, 보조 글자 최소 13px, 버튼 높이 40~44px | 고령 사용자 가독성과 현장 태블릿 터치 |
| 모바일에서 지도를 목표 설정보다 먼저, 지도 아래에 현재 상황 표시 | 현장 동행(Get) 단계에서 지도가 주 입력이다 |
| 50ha 버튼 이름을 "개선안"에서 "상향 검토"로 | 협의체 발표 표현과 맞춤 |

## 4. 타겟이 편하게 보는 화면과 브랜드 적용 (2026년 11월)

세 화면(후보단지 찾기 · 거절 대응 · 단지 운영 설계)에 '모두의 농장' 브랜드를 입히면서, 타겟이 편하게 읽는 화면의 근거를 다시 조사했다.

### 4.1 근거

| 사실 | 출처 | 화면에 주는 뜻 |
|---|---|---|
| 농업법인 대표 평균 나이 55세(2023, 2014년 47.9세) | 한국농촌경제연구원 보고서 인용 보도(헤럴드경제) | 쓰는 사람도 노안이 오는 나이다. 글자를 키운다 |
| 디지털정보격차 조사의 농업인 중 60대 이상 61.5%(2021) | 노년 농업인 디지털 이용 실태 연구(한국산학기술학회 2023 춘계) | 설명 대상인 조합원은 더 고령이다 |
| 본문 최소 16px, 표준 17px, 줄 간격 150% 이상. 글자 크기를 사용자가 고르는 단계 설정 제공 | 범정부 UI/UX 디자인 시스템(KRDS) 타이포그래피 | 본문 17px, 줄 간격 1.6, 머리글에 글자 크기 3단계 |
| 고령자는 큰 글자를 일관되게 선호하지만, 너무 크면 오히려 읽는 속도가 떨어진다 | Hou 외(2022), Frontiers in Psychology 체계적 문헌 검토 | 무조건 키우지 않고 단계(100·112.5·125%)로 고르게 한다 |
| 나이가 들수록 대비 감도가 떨어지고, 특히 파랑·초록 계열에서 색 구분이 둔해진다 | 고령자 웹 접근성 가이드 정리(Netguru 등) | 초록 브랜드에서 글자는 진한 초록(8:1 이상)만 쓰고, 색만으로 뜻을 전하지 않는다 |
| 메뉴를 숨기면 고령 사용자가 길을 잃는다(낯익은 포털·정부 사이트처럼 메뉴가 늘 보여야 한다) | KRDS 내비게이션 원칙, NN/g 고령 사용자 연구 요약 | 휴대폰에서도 햄버거 메뉴 없이 세 화면을 늘 보여 준다 |

### 4.2 키 컬러 (브랜드 키트 세트 A '모이는 들녘'에서)

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 들녘 초록 `#1F7A4D` | 주색 | 주 버튼, 지금 화면 메뉴, 선택한 대안, 포커스 테두리 |
| 새순 연두 `#3F9F60` · 테두리 `#2E9360` | 법인 단지 | 지도의 법인 단지(참여 필지) |
| 볏짚 노랑 `#F2B134` · 테두리 `#A66909` | 들어오는 땅 | 지도의 편입 땅·편입 후보, '다음 할 일' 칸의 띠 하나. 로고에서 기울어진 채 도착하는 노란 조각과 같은 뜻 |
| 빨강 `#B4312B` + 빗금 | 거절 | 거절한 땅. 녹색맹에서 볏짚과 비슷해 보이므로(ΔE 16) 빗금을 함께 넣는다 |
| 파랑 `#196AAF` | 교환 | 경작권 교환. 세 화면 모두 같은 뜻 |
| 잉크 `#141F18` · 바탕 `#F9FBFA` | 글자 · 바탕 | 초록 쪽으로 살짝 기운 중성색 |

후보단지·단지 운영 화면의 차트 계열색도 같은 뜻으로 맞췄다(법인·단지 초록, 강조 볏짚, 교환 파랑). 색약 시뮬레이션(Machado 2009)에서 가장 가까운 짝의 색 거리(ΔE)는 기존 파랑·주황·청록 25.0에서 30.2로 오히려 커졌다.

### 4.3 화면에서 바꾼 것

| 바꾼 것 | 근거 |
|---|---|
| 공통 머리글: 연한 초록 단색 띠(#DAF7E4) + 컬러 로고(모두의 농장) + 진한 초록 글자(7.9:1). 흰 글자는 #2A834A보다 밝은 바탕에서 4.5:1 아래로 떨어져 연한 띠에서는 쓰지 않는다 · 메뉴 3개(후보단지 찾기 · 거절 대응 · 단지 운영 설계) · 글자 크기 3단계. 지금 화면은 흰 알약(휴대폰은 바탕색 탭)으로 표시 | 브랜드 가이드의 밝은 바탕 컬러 로고 조합(PAPER · FULL COLOUR), KRDS 글자 크기 설정. 그라데이션(green-100 → 200)과 단색 green-200도 비교했으나, 브랜드의 평면 초록에 맞추고 화면에서 튀지 않는 단색 green-100을 골랐다. 띠와 페이지 바탕 차이가 작아 아래에 새순 연두 경계선을 둔다. 어두운 화면에서는 깊은 초록 띠 + 흰 로고 |
| 메뉴는 일 순서대로, 사무장이 쓰는 말로 ("빈 필드" 대신 "거절 대응") | 단지를 정하고 → 설득하다 거절을 맞고 → 운영을 짠다 |
| 화면 제목 줄: 메뉴 이름(작게) · 제품 이름 · 한 줄 설명 | 지금 어느 화면인지 메뉴와 같은 말로 다시 알려 준다 |
| 공통 바닥글: 흰 로고, 세 화면 바로가기, 근거 데이터, "추정치이며 약속된 금액이 아님" | 배당 신뢰 문제. 숫자의 출처를 늘 보이게 한다 |
| 본문 바로가기 링크 | KRDS·WCAG 2.4.1 |
| 글자 크기를 rem 단위로 바꾸고, 크게 고르면 결과 칸을 지도 아래로 내림 | 큰 글자에서도 표가 깨지지 않게 |
| 글꼴 Wanted Sans, 숫자는 같은 폭 | 브랜드 글꼴. 금액 표의 자릿수가 세로로 맞는다 |
| 세 화면 모두 글자 대비 4.5:1 이상(밝은·어두운 화면), 지도 테두리 3:1 이상 | WCAG 1.4.3 · 1.4.11 |

## 5. 인터뷰에서 확인할 것

- 거절 뒤 대표에게 무엇을 어떤 형식으로 보고하나? (구두·문서·단톡방)
- 남은 농가가 실제로 물은 질문은 무엇이었나? 평당 배당인가, 지급 시기인가, 흉년인가?
- 설명회에서 종이 자료를 나눠 주나? 글자 크기와 분량은 어느 정도가 좋은가?
