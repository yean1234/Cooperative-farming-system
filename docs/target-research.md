# 타겟 분석 — 빈 필드 시뮬레이터는 누구에게 무엇을 보여 줘야 하나

빈 필드 시뮬레이터(`web/empty-field.html`)의 화면 설계 근거다. 공개 자료와 최종발표의 고객 가설로 타겟을 정하고, 화면에서 바꾼 부분을 그 근거에 연결한다.
인터뷰 전 가설이다. 인터뷰 답변이 들어오면 이 문서와 화면을 함께 고친다.

## 1. 공개 자료에서 확인한 사실

| 사실 | 출처 | 화면에 주는 뜻 |
|---|---|---|
| 지원은 법인당 2년 최대 20억 원(국비 50·지방비 40·자부담 10%). 2026 시범 6개 법인 | 뉴시스, 농식품부 공동영농 확산 민·관 협의체 첫 회의(2026.7.27) | 지원 자격을 잃는 손실이 크다. 자격 판정을 화면 맨 위에 둔다 |
| 면적 기준 상향(20ha→50ha), 벼 포함을 검토 중. 개선안은 2026년 11월까지 | 같은 협의체, 농식품부 차관 경주 대청 현장 점검 보도 | 기준이 바뀔 수 있다. 기준을 고정하지 않고 고를 수 있게 둔다 |
| 협의체 검토 과제: 농지 집적화, 품목 구성, **소득 배분**, 사업 운영 | 같은 협의체 | 배분 방식(배당·임차료·혼합) 비교가 정책 쟁점과 맞닿아 있다 |
| "확산에는 신뢰와 참여가 가장 중요" | 같은 협의체, 차관 발언 | 약속처럼 보이는 숫자 대신 범위와 추정치임을 밝힌다 |
| 배당 법인 10개소(2026.2), 의성 화성영농조합법인 평당 2,000원 배당 | 경북매일(2026.3.17) | 농가는 "평당 얼마"로 생각한다. 평·만 원 단위로 보여 준다 |
| 농가 인구 중 65세 이상 51.3%(잠정, 농가) · 51.0%(확정, 농림어가) | 국가데이터처 2025 농림어업총조사(잠정 2026.4.28, 확정 2026.9.29) | 설득 대상 조합원 절반이 고령이다 |
| 디지털 역량 수준(일반 국민 대비): 농어민 72.4%, 고령층 56.2% | 과기정통부·NIA 2025 디지털정보격차 실태조사(2026.3) | 조합원은 화면을 직접 쓰지 않는다. 사무장이 인쇄해 건넬 큰 글자 자료가 필요하다 |

> 발표자료의 "농업인 5명 이상" 요건은 공개 보도에서 확인하지 못했다. 공고문 원문으로 확인한 뒤 쓴다. 화면에서는 최소 참여 농가를 바꿀 수 있게 두었다.
> 65세 이상 비율은 확정 결과(51.0%, 농림어가 기준)가 나왔다. 발표자료의 51.3%는 잠정 결과(농가 기준)다.

## 2. 세 사람이 각자 원하는 것

최종발표의 구매 구조(사무장이 쓰고, 대표가 정하고, 법인이 비용을 낸다)를 따랐다.

| 누구 | 역할 | 거절 당일 묻는 것 | 받아야 할 것 |
|---|---|---|---|
| 사무장 | 최종사용자 | 빼고 가도 지원 기준이 지켜지나? 메워야 하면 누구를 설득하나? | 한 줄 결론, 1순위 대안, 설득할 농가 수 |
| 대표 | 의사결정자 | 순수익이 얼마나 줄고, 어떤 안을 고를까? | 대안 3개 비교와 권고, 결정할 일이 적힌 한 장 |
| 남은 조합원 | 설득 대상(간접) | 내 배당이 줄어드나? 흉년이면 어떻게 되나? | 평당 배당과 내 땅 기준 금액, 흉년 손해를 누가 지는지 |

시뮬레이터로 확인한 핵심 숫자도 있다. 흥해 단지 6에서 한 농가가 빠지면 법인 순수익은 3~10% 줄지만, 남은 조합원 평당 배당은 0.3% 안쪽으로만 줄었다. 땅과 배당받을 사람이 함께 빠지기 때문이다. 이 숫자가 조합원 설득의 첫 문장이 된다.

## 3. 화면에서 바꾼 것

| 바꾼 것 | 근거 |
|---|---|
| **결론 영역**을 화면 맨 위로 올림: 빼고 갈지·메울지 한 줄, 지원 기준, 법인 순수익 변화, 남은 조합원 평당 배당 변화, 다음 할 일(1순위 대안) | 사무장이 가장 먼저 묻는 질문. 이전에는 오른쪽 탭 안 배너에 있었다 |
| 판정 시간 표시(예: 판정 0.01초) | 가치제안 "1초 안에 판정"을 화면에서 바로 보여 준다 |
| **거절 기록**: 거절한 순서대로 농가와 면적, 농가별 복구 버튼 | 여러 농가가 거절하면 누가 빠졌는지 기억해야 했다. 지도를 다시 찾지 않고 되돌린다 |
| **설명 자료 만들기**: 대표 보고용 한 장, 농가 설명용 한 장(인쇄, A4) | 대표는 결정, 조합원은 종이로 받는다. 디지털 역량 격차를 사무장이 메운다 |
| 농가 설명용 자료: 글자 크게, 평당 배당과 1,000·2,000·3,000·5,000평 기준 연 금액, 흉년 손해를 지는 쪽, "추정치이며 약속이 아님" | 고령 조합원, 평 단위 사고, 배당 신뢰 문제 |
| 배당금·흉년 탭 첫 줄에 "흉년이면 배당형은 조합원이, 고정 임차료형은 법인이 손해" 문장 | 발표 인사이트 "흉년은 따로 보여 줘야 설득된다" |
| 본문 16px, 보조 글자 최소 13px, 버튼 높이 40~44px | 고령 사용자 가독성과 현장 태블릿 터치 |
| 모바일에서 지도를 목표 설정보다 먼저, 지도 아래에 현재 상황 표시 | 현장 동행(Get) 단계에서 지도가 주 입력이다 |
| 50ha 버튼 이름을 "개선안"에서 "상향 검토"로 | 협의체 발표 표현과 맞춤 |
