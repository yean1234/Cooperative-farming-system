# 실측 데이터 연동

후보단지 시뮬레이터는 이제 공개 실측 자료로 만든 지도를 기본으로 연다. 가상 읍면은 시험용으로 남겨 두었다.
저장소에 들어 있는 지도는 `data/regions/heunghae.json` 한 곳이다.

- 범위: 포항시 북구 흥해읍 용천·흥안·망천·금장·약성리 들녘, 경도 129.3405~129.3743, 위도 36.113~36.135(약 3.0km × 2.4km)
- 규모: 팜맵 필지 2,666개, 489ha. 논 2,038개, 밭 467개, 시설 140개, 과수 21개. 경지정리 필지 71%
- 생성: 2026-10-29. 흙토람은 PNU 2,383개 중 950개를 직접 조회했다(필지 1,094개). 나머지 1,572개 필지는 인접 조회 필지 값으로 채웠다.
  같은 빌드 명령을 이틀 더 돌리면 모든 PNU를 직접 조회한 값으로 바뀐다(3절).

## 1. 속성별 출처

| 시뮬레이터 속성 | 출처 | 인증키 | 저장소 지도 |
|---|---|---|---|
| 필지 경계, 논·밭·과수·시설(`land_use`), 대표지목(`jimok`), 대표 PNU, 경지정리 여부(`consolidated`) | 팜맵 공간정보 SHP(농림축산식품부·농림수산식품교육문화정보원, 2025년 12월 기준) | 불필요(파일 내려받기) | 사용 |
| 도로 접속(C5), 지도의 도로선 | OpenStreetMap(Overpass API) + 경지정리 여부 | 불필요 | 사용 |
| 경사(C6) 대체값 | Copernicus DEM GLO-30(30m) | 불필요 | 사용 |
| 경사 등급, 배수등급(C8), 논·밭 적성등급 | 흙토람 토양특성 상세정보 V3·단면정보 V2(농촌진흥청) | `DATA_GO_KR_KEY` | 사용(PNU 950개 직접 조회, 나머지 인접 보간) |
| 지목 '도' 필지 인접(도로 접속 보강), 공시지가 | 연속지적도 `LP_PA_CBND_BUBUN`(국토교통부, 브이월드) | `VWORLD_KEY` | 사용(지적 필지 7,181개, 공시지가 2025년 기준) |
| 소유자·참여 농가 | 농지대장 비공개 | 없음 | 필지 수로 추정 |

흙토람 값이 들어가자 결과가 달라졌다. 같은 기본 조건(대리 지표 모드)에서 비교했다.

| 지도 상태 | 후보 단지 | 단지 면적 | 연 소득 증분(기준) |
|---|---|---|---|
| 키 없음(배수 '보통' 일괄, DEM 경사) | 10곳 | 285.8ha | 581.8백만원 |
| 흙토람·연속지적도 연동 | 9곳 | 253.0ha | 349.3백만원 |

흥해 들녘 논은 대부분 배수 '약간양호'(790개), '약간불량'(847개), '매우불량'(293개)이다.
배수 불량 논은 벼 단작으로 계산하므로 소득 증분이 줄었다. 배수 동질성(C8)도 이제 실제로 필지를 걸러낸다.

흙토람 키가 없으면 모든 필지를 배수 '보통', 토양 2등급으로 계산한다. 이때는 배수 동질성(C8)이 아무것도 걸러내지 못한다.
화면 상단 경고와 '데이터 출처' 카드에 지도 상태가 표시된다.

## 2. 인증키 발급

### 공공데이터포털(흙토람 토양 API)

1. https://www.data.go.kr 에 회원가입하고 로그인한다.
2. 아래 두 페이지에서 각각 **활용신청**을 누르고 활용목적을 적는다. 개발계정은 자동승인이다.
   - 토양도 기반 토양특성 상세 정보 V3: https://www.data.go.kr/data/15144225/openapi.do
   - 토양도 기반 토양특성 단면정보 V2: https://www.data.go.kr/data/15144105/openapi.do
3. **마이페이지 → 데이터 활용 → Open API → 활용신청 현황**에서 일반 인증키(Decoding)를 복사한다.
   키 하나로 두 API를 함께 쓴다.

개발계정 한도는 API마다 하루 1,000건이다.

### 브이월드(연속지적도)

1. https://www.vworld.kr 에 회원가입하고 로그인한다.
2. 상단 **오픈API → 인증키 발급 → 발급 바로가기**로 들어간다(마이페이지 → 오픈API → 인증키 발급).
3. 서비스 URL에 `http://localhost`를 적고, 활용 API에서 **2D 데이터 API**를 고른다.
   연구·개인용이면 **개발키**를 받는다(브이월드 FAQ 기준). 개발키는 연장되지 않으므로 만료되면 새로 받는다.

### 키 넣기

```bash
cp .env.example .env   # DATA_GO_KR_KEY, VWORLD_KEY, VWORLD_DOMAIN을 채운다
```

## 3. 지도 만들기

1. 팜맵 SHP를 내려받는다. 경상북도는 https://www.data.go.kr/data/15104488/fileData.do 이다(약 470MB, 시군별 SHP).
   다른 시도는 같은 제공기관의 `팜맵공간정보_<시도>` 파일데이터(15104481~15104491)를 받는다.
2. 압축을 풀고 대상 시군의 `.shp` 경로를 넘겨 빌드한다.

```bash
python -m server.realdata.build \
  --farmmap-shp "<압축 푼 폴더>/2025_경상북도_포항시/2025_경상북도_포항시.shp" \
  --bbox 129.3405,36.113,129.3743,36.135 \
  --name "포항시 흥해읍 용천·흥안·망천 들녘" \
  --out data/regions/heunghae.json
```

흥해 지도를 이어서 채울 때(하루 한 번, 이틀 더)는 아래 명령을 그대로 돌린다.
포항시 팜맵 SHP는 처음 만든 PC의 `data/raw/farmmap/`에 복사해 두었다(104MB, git 제외). 다른 PC에서는 1번부터 다시 받는다.

```bash
python -m server.realdata.build --farmmap-shp data/raw/farmmap/pohang_2025.shp \
  --bbox 129.3405,36.113,129.3743,36.135 --name "포항시 흥해읍 용천·흥안·망천 들녘" \
  --soil-budget 950 --out data/regions/heunghae.json
```

- `.env`에 키가 있으면 흙토람·연속지적도 단계도 함께 돈다. 키가 없으면 그 단계를 건너뛴다.
- 외부 응답은 `data/cache/`에 저장한다(git 제외). 흙토람 한도를 넘으면 조회한 만큼만 반영하고 경고를 남긴다.
  다음 날 같은 명령을 다시 돌리면 캐시 다음부터 이어 받는다. `--soil-budget`으로 한 번에 부를 건수를 줄일 수 있다.
- 범위가 넓으면 브이월드 요청은 2km² 이하 상자로 자동으로 나눈다. DEM은 1°×1° 타일 경계를 넘으면 범위를 나눠 달라고 멈춘다.
- 만든 JSON은 `data/regions/`에 두면 화면의 '실측 지도' 목록에 나타난다. `python -m server.sites_cli --geojson data/regions/heunghae.json`으로 명령줄에서도 돌릴 수 있다.

## 4. 변환 규칙

### 팜맵

| 팜맵 `CLSF_NM` | `land_type` | `land_use` | 선정 대상 |
|---|---|---|---|
| 논 | 답 | 논 | 예 |
| 밭 | 전 | 밭 | 예(밭 포함 설정 시) |
| 과수 | 과 | 과수 | 아니오 |
| 시설 | 전 | 시설 | 아니오 |
| 비경지 | 지도에서 제외 | | |

지적 지목이 아니라 영상 판독 분류를 쓴다. 지목이 '답'이어도 실제로 밭으로 쓰면 밭으로 본다. 지적 지목은 `jimok`에 따로 둔다.

### 흙토람 코드(기술명세서 3.1절)

| 항목 | API 코드 | 시뮬레이터 값 |
|---|---|---|
| 경사 `Soilslope_Cd` | 01 0–2%, 02 2–7%, 03 7–15%, 04 15–30%, 05 30–60%, 06 60–100% | 구간 중앙값 1.0, 4.5, 11, 22.5, 45, 80(%) |
| 배수 `Soildra_Cd` | 01 매우양호, 02 양호, 03 약간양호, 04 약간불량, 05 불량, 06 매우불량 | 01·02 → 1 양호, 03 → 2 보통, 04~06 → 3 불량 |
| 적성 `Rfld_Grd_Cd`(논)·`Pfld_Grd_Cd`(밭) | 1~5급지 | 1~4등급(5급지는 4) |

배수 '약간불량'을 '불량'으로 묶은 것은 우리 판단이다. 논콩·밀 이모작은 습해에 약해서 보수적으로 잡았다.
이 선택이 결과를 꽤 바꾼다. '약간불량'을 '보통'으로 풀면 흥해 지도는 단지 8곳, 232.5ha, 소득 증분(기준) 419.2백만원이 된다.
기본값은 9곳, 253.0ha, 349.3백만원이다. 현장 배수 개선(암거·명거) 계획이 있으면 완화하는 쪽이 맞다.

- 조회 순서: 480m → 240m → 120m → 60m 격자 순으로 칸마다 한 필지씩 고른다. 하루 한도에서 어디서 끊기든 들녘 전체가 고르게 덮인다.
  흥해 지도에서 첫날 950건을 부르면 모든 필지가 직접 조회 필지에서 118m 안에 들어온다(95%는 83m 안).
- 빈칸 채우기: 직접 조회하지 못한 필지는 300m 안의 가장 가까운 조회 필지 값을 쓴다. 논은 논, 밭은 밭을 먼저 찾는다.
  출처에는 `흙토람(인접 필지)`로 남긴다.
- 오류 처리: 초당 호출 초과나 게이트웨이 시간 초과는 잠시 뒤 다시 부른다. 일일 한도 초과는 그 API만 멈추고 받은 데까지 반영한다.
  오류 응답은 캐시에 남기지 않는다.

### 경사 대체값(DEM)

필지 중심과, 꼭짓점을 중심 쪽으로 60% 당긴 점에서 경사를 쌍선형 보간해 평균한다.
30m 격자 표면모델이라 작은 필지의 미세 경사나 계단식 논두렁은 잡지 못한다. 흙토람 경사가 있으면 그 값을 쓴다.

흥해 지도에서 두 출처를 맞대 보면 순서가 일치한다. DEM은 30m 평활화 때문에 조금 낮게 나온다.

| 흙토람 경사 등급 | 필지 수 | DEM 경사 중앙값 |
|---|---|---|
| 0–2% | 1,853 | 0.9% |
| 2–7% | 688 | 1.8% |
| 7–15% | 119 | 5.0% |
| 30–60% | 3 | 37.5% |

DEM 값은 지도 속성 `slope_dem`에 계속 남겨 둔다.

### 도로 접속(C5)

다음 중 하나면 접속으로 본다. 근거는 필지 속성 `road_source`에 남긴다.

1. 필지 경계가 OSM 도로 중심선에서 7m 이내다. 보행 전용 길은 뺀다.
2. 경지정리 필지다. 경지정리는 구획마다 농로가 닿도록 설계한다.
3. 지적 '도' 필지와 경계가 3m 이내다. 브이월드 키가 있을 때만 쓴다.

흥해 지도에서 OSM 기준 접속률은 경지정리 필지 78%, 미정리 필지 37%였다.
경지정리 필지의 나머지 22%는 OSM에 없는 농로로 보고 2번 규칙으로 보완했다.
최종 접속은 OSM과 경지정리만 쓰면 2,666개 중 2,210개, 지적 도로 필지까지 쓰면 2,393개다.

## 5. 소득 증분 근거

소득자료의 '소득'은 직불금이 빠진 값이어서 직불금을 따로 더했다.

주의할 점:

- 2025년은 쌀값이 크게 오른 해다. 2025년 가격에서는 콩 단작으로 바꾸면 벼보다 소득이 낮고, 밀과 이모작해야 직불금 덕분에 앞선다.
- 가루쌀과 '논콩'만의 공식 소득 수치는 없다. 콩 소득은 논콩과 밭콩을 합친 값이다.
- 토양등급별 수량 계수(1.00/0.95/0.88/0.80)는 여전히 가정값이다.

## 7. 한계

- **소유자**: 농지대장이 비공개라 참여 농가 수(C3)는 필지 수 ÷ 2.5로 추정한다. 실제 적용 때는 지자체·법인 자료로 바꿔야 한다.
- **정답 단지 없음**: 실측 지도에는 이미 조성된 공동영농 단지 경계가 없다. 그래서 재현 검증(F1·IoU)은 가상 읍면에서만 돈다.
- **OSM 완결성**: 농로가 빠진 곳이 있다. 연속지적도 키를 넣으면 지적 '도' 필지로 보강된다.
- **팜맵 판독 시점**: 필지마다 판독 영상 촬영일이 다르다. 흥해 지도는 2019~2024년 영상이다.
